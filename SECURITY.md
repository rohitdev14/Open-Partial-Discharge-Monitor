# Security and Safety Reporting

This project interfaces with monitoring systems that may be deployed near energized electrical equipment and industrial networks.

Do not publish credentials, private network details, exploitable deployment information, or sensitive site data in issues.

For now, before a dedicated private reporting channel is established, avoid posting exploitable security details publicly. Maintainers will add a formal private reporting process before production deployment guidance is released.

## Safety boundary

This project is monitoring software. It is not a protection relay, safety instrumented system, or authorization to work on energized equipment. Do not use software outputs as the sole basis for automatic trip or safety-critical control.
